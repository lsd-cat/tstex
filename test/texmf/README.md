Copied unchanged from TeX Live 2026 (found via kpsewhich): plain.tex, hyphen.tex, story.tex under Knuth's licence; the Computer Modern .tfm files (every font plain.tex loads) are public.

big100.tfm is cmr10.tfm with the design size (header word 1) patched to 100pt; only m2-review-font-2048 uses it (the tex.ch "scaled to 2048pt or higher" check).

trip.tfm is built from Knuth's spec/trip.pl (tripman step 1) with `/Users/g/texlive/2026/bin/universal-darwin/pltotf spec/trip.pl test/texmf/trip.tfm` (pltotf from TeX Live's `fontware` package); `tftopl` of the result reproduces trip.pl exactly. Only tools/trip.ts uses it.

etrip.tfm is built the same way from spec/etrip.pl (etripman step 6): `pltotf spec/etrip.pl test/texmf/etrip.tfm`. Only tools/trip.ts uses it.

images/ (M6 image tests; fig.png etc. are one downscaled desktop picture, resolved as `images/NAME` relative to a root, oracle.sh copies the dir into the temp cwd): fig.png (8-bit RGB), fig.jpg (baseline JPEG, sips), fig-gray.png (8-bit grayscale, sips with the Generic Gray profile), fig-pal.png (8-bit palette, 64 colours, ImageMagick `magick fig.png -colors 64 PNG8:fig-pal.png`; sips cannot write palette PNGs).

ec-lmr10.tfm (Latin Modern, TeX Live fonts/tfm/public/lm) is only for m6-pdf-fonts-enc (a font re-encoded via lm-ec.enc in pdftex.map).

images/boxes.pdf (a hand-written 3-page PDF 1.4 with MediaBox/CropBox/BleedBox/TrimBox/ArtBox variations, incl. a CropBox wider than the MediaBox) and images/bad.pdf (8 bytes of garbage) come from the M6 backend review (/tmp/rv); used by the m6-review-pdfimage-* tests.

images/j_trunc.jpg (20 bytes: SOI and a JFIF APP0 segment, nothing after it; M6 backend review) is for m6-review-jpeg-trunc.

PNG fixtures from the M6 backend review (/tmp/rv): images/pal4.png (7x10 4-bit palette, rows end in padding bits), images/ga.png (7x10 8-bit gray+alpha), images/crc.png (7x10 RGB whose IHDR CRC is off by one). images/rgba.png and images/rgba16.png (5x3 RGB+alpha, 8 and 16 bits, rows filtered None/Sub/Paeth) are generated by a 20-line Node script (zlib deflateSync + crc32, hand-written chunks). Used by the m6-review-png-* tests.

M8 fixtures (images/; each PDF has its generating source next to it as NAME.src.tex, built with TeX Live pdftex/pdflatex under SOURCE_DATE_EPOCH=0 FORCE_SOURCE_DATE=1; pages are small, 1-4 in wide):
- fig-simple.pdf (1 page, PDF 1.4, uncompressed, cmr10 text + rule, 10 objects), fig-compressed.pdf (same content, `\pdfminorversion=5 \pdfcompresslevel=9 \pdfobjcompresslevel=2`: PDF 1.5 with /ObjStm and an /XRef stream), fig-tikz.pdf (pdflatex + TikZ, colours, rotated/scaled scope, text; compressed default so PDF 1.5 with ObjStm + XRef), fig-multipage.pdf (3 pages; page 2 has /Rotate 90, page 3 is 4in wide, others 3in), fig-boxes.pdf (MediaBox 288x216 with different CropBox/BleedBox/TrimBox/ArtBox via `\pdfpageattr`), fig-fonts.pdf (cmr10, cmbx10, cmti10 as Type1 subsets, three /FontFile streams), fig-nested.pdf (includes fig-simple.pdf as a Form XObject), fig-image.pdf (includes fig.png).
- fig-encrypted.pdf is not provided: pdftex cannot write encrypted PDFs (a unit test for the engine can build one by hand).
- PNGs, all 40x30, made with ImageMagick from fig.png (`-define png:exclude-chunk=all`), then chunks added/removed with a small Node script (fix.mjs: parse chunks, insert tRNS/gAMA before IDAT, recompute CRC): interlaced.png (8-bit RGB, Adam7), rgb16.png (16-bit RGB), gray16.png (16-bit gray), trns-pal.png (8-bit palette, 16 colours, tRNS with 8 alpha entries), trns-rgb.png (8-bit RGB, tRNS colour key = first palette colour of trns-pal), gamma.png (8-bit RGB, gAMA 45455, no sRGB chunk).
- m8-subset-seac uses ly1-zi4r-0 (Inconsolata zi4, LY1): its eacute/ntilde/udieresis charstrings use seac (the subset also contains /e /n /u /acute /tilde /dieresis); Latin Modern, Times (utmr8a) and cm-super glyphs do not use seac.
- Packages installed with tlmgr for m8-latex-acmart: xkeyval xstring libertine inconsolata newtx zi4 environ trimspaces totpages everyshi hyperxmp ncctools preprint upquote times and others acmart needs (tlmgr also re-ran updmap, so pdftex.map now lists their fonts).

rvf.vf/rvf.tfm (M8 VF review) are built with `vptovf` (TeX Live fontware) from `(DESIGNSIZE R 10.0)(MAPFONT D 0 (FONTNAME cmr10))(CHARACTER C A (CHARWD R 1.0)(MAP (SETCHAR C A)(SETRULE R 0.4 R 0.2)(SETCHAR C B)))`; rvf2.tfm is a copy of cmr10.tfm and rvf2.vf a copy of rvf.vf (characters without a packet). oracle.sh sets VFFONTS to this dir. Used by m8-review-vf-rule*.

M8 review fixtures (hand-written PDFs from the cold reviewers' /tmp/rev/cases/NAME/x.pdf and /tmp/rv/t3): images/rev-bigreal.pdf (reals ≥ 2^31 in a page dict), rev-nolen.pdf (a stream without /Length), rev-ver125.pdf (`%PDF-1.25` header), rev-unkfilter.pdf (`/Filter /Foo`), rev-charset-empty.pdf (a font descriptor with `/CharSet ()`), rev-runaway.pdf (one page; the test asks for page 2), rev-t3-ws.pdf (`/CharSet ( /H/e /o)`), rev-t3-empty.pdf (`/CharSet ()` from /tmp/rv/t3). Used by m8-review-epdf-* and m8-review-charset-*.
