pdfLaTeX in your browser — no server GitHub npm

Works: Type 1 fonts, PNG/JPEG/PDF figures, hyperref, TikZ/pgf, beamer, microtype, SyncTeX, multi-run builds. Does not: XeLaTeX/LuaLaTeX, OpenType/TrueType, shell escape (minted), EPS, Biber, BibTeX (not yet), PK fonts. Output is byte-identical to pdflatex. Letters need the basic bundle.
